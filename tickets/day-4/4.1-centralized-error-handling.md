# 4.1 — Add centralized error-handling middleware

**Labels:** feature, middleware, day-4

## Branch
Before starting, create your branch:
```
git checkout -b error-handling-middleware
```

## Description
Add an Express error-handling middleware (4-arg function) so errors aren't handled ad hoc in each controller.

## Acceptance Criteria
- [ ] `middleware/errorHandler.js` catches errors passed via `next(err)`
- [ ] Returns consistent JSON shape, e.g. `{ error: "message" }`
- [ ] Applied as the last middleware in `app.js`/`server.js`
- [ ] At least 2 existing controllers updated to use `next(err)` instead of handling errors inline

## Submit
When your acceptance criteria are all checked off:
```
git add .
git commit -m "your message here"
git push origin error-handling-middleware
```
Your commit message should summarize what you actually changed (not just "done" or "fix") — write it like you're telling a teammate what this branch does.

Then open a Pull Request on your own fork's GitHub page (base: your `main`, compare: your branch) and add **your-instructor-github-username** as a reviewer.
