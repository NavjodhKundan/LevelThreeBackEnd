# 4.2 — Add input validation to POST and PUT

**Labels:** feature, validation, day-4

## Branch
Before starting, create your branch:
```
git checkout -b input-validation
```

## Description
Validate incoming product data before it reaches Supabase, so bad requests fail fast with a clear message.

## Acceptance Criteria
- [x] `POST /products` rejects requests missing `name` or `price` with a `400` and a clear error message
- [x] `price` must be a positive number — reject otherwise with `400`
- [x] `PUT /products/:id` applies the same validation rules
- [x] Validation logic lives in its own middleware/function, not copy-pasted inline in both routes

## Submit
When your acceptance criteria are all checked off:
```
git add .
git commit -m "your message here"
git push origin input-validation
```
Your commit message should summarize what you actually changed (not just "done" or "fix") — write it like you're telling a teammate what this branch does.
