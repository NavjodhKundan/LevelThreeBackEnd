## Description
Move the logic from Ticket 2.1 out of a single file into a `routes/` and `controllers/` structure, matching what was shown in class.

## Acceptance Criteria
- [ ] `routes/products.routes.js` only defines paths + HTTP methods, delegates to controller functions
- [ ] `controllers/products.controller.js` contains the actual logic for each route
- [ ] All 4 endpoints from Ticket 2.1 still work identically
- [ ] `server.js`/`app.js` only wires up the router, no inline route logic
