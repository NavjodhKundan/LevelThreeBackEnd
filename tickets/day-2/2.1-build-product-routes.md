# 2.1 — Build product routes against Supabase

**Labels:** feature, day-2

## Branch
Before starting, create your branch:
```
git checkout -b product-routes
```

## Prerequisite
Before starting this ticket, make sure you've completed [`supabase/README.md`](../../supabase/README.md) — your own Supabase project should be linked and pushed, with the `products` table seeded with 44 sample rows. Check your Supabase dashboard's Table Editor to confirm the data is there.

## Description
Build the four basic product endpoints directly against the real `products` table in Supabase, using the `supabaseClient.js` config that's already set up in this repo. You don't need to build the Supabase connection yourself yet — that'll be explained in detail on Day 3. For now, just import `supabase` from `src/config/supabaseClient.js` and use it.

When testing `POST`, use a product name that isn't already in the seeded list (check the Table Editor first) so you don't create a confusing duplicate — e.g. prefix your test products with your own name, like `"Alex Test Tent"`.

## Acceptance Criteria
- [ ] `GET /products` returns all rows from the `products` table as JSON
- [ ] `GET /products/:id` returns a single row, or 404 if not found
- [ ] `POST /products` inserts a new row and returns it
- [ ] `PUT /products/:id` updates an existing row and returns it, or 404 if not found
- [ ] `DELETE /products/:id` removes a row and returns a success message, or 404 if not found
- [ ] Server runs with `npm run dev` without errors
