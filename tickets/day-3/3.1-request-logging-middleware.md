# 3.1 — Add request logging middleware

**Labels:** feature, middleware, day-3

## Branch
Before starting, create your branch:
```
git checkout -b logging-middleware
```

## Description
Add a simple middleware function that logs the method, path, and timestamp of every incoming request.

## Acceptance Criteria
- [ ] Middleware is in its own file (e.g. `middleware/logger.js`)
- [ ] Applied globally in `app.js`/`server.js`
- [ ] Every request logs something like `[2026-09-14T10:00:00Z] GET /products`

## Submit
When your acceptance criteria are all checked off:
```

git push origin logging-middleware
```
Your commit message should summarize what you actually changed (not just "done" or "fix") — write it like you're telling a teammate what this branch does.
