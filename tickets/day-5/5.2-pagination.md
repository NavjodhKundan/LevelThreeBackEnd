# 5.2 — Add pagination to GET /products

**Labels:** feature, day-5

## Branch
Before starting, create your branch:
```
git checkout -b pagination
```

## Description
Support paging through the product list instead of always returning every row at once.

## Acceptance Criteria
- [ ] `GET /products?page=1&limit=10` returns only that page's worth of rows
- [ ] Response includes the total count of matching products (e.g. in a header or a wrapping object like `{ data: [...], total: 42 }`)
- [ ] Missing `page`/`limit` default to sensible values (e.g. page 1, limit 20)
- [ ] Works together with the filtering/sorting from Ticket 5.1 (e.g. `?minPrice=10&sort=price_asc&page=2`)
