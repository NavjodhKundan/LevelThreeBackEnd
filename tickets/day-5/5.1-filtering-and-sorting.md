# 5.1 — Add filtering and sorting to GET /products

**Labels:** feature, day-5

## Branch
Before starting, create your branch:
```
git checkout -b filtering-and-sorting
```

## Description
Let clients narrow and order the product list using query params, instead of always returning every row in default order.

## Acceptance Criteria
- [ ] `GET /products?minPrice=X&maxPrice=Y` filters results to that price range
- [ ] `GET /products?sort=price_asc` and `sort=price_desc` order results by price
- [ ] Invalid/missing query params fall back to the unfiltered, default-ordered list (no error)
- [ ] Filtering and sorting logic is implemented using Supabase query builder methods (`.gte()`, `.lte()`, `.order()`), not manual JS array filtering after the fact
